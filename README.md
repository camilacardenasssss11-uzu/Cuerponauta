# Cuerponauta

Canal de YouTube de curiosidades de ciencia y cuerpo humano.
Videos de 5 a 7 minutos, para adultos curiosos. No es contenido para niños.

**Idea:** explorar el cuerpo humano por dentro, una pregunta a la vez.
**Formato:** 1 pregunta imposible + respuesta en 6 minutos + 1 dato wow al final.
**Idioma:** español.

## Estructura

```
cuerponauta/
├── README.md               # este archivo
├── ideas/
│   └── ideas.md            # banco de ideas por misión (30 ideas iniciales)
├── guiones/
│   ├── PLANTILLA-guion.md  # plantilla para cada video nuevo
│   └── 01-bostezo-contagioso.md
├── produccion/
│   └── checklist.md        # checklist de grabación / edición / publicación
├── publicados/
│   └── README.md           # registro de videos publicados
├── assets/
│   └── miniaturas/         # miniaturas finales (.png/.jpg)
└── docs/
    └── CANAL.md            # posicionamiento, pilares y monetización
```

## Flujo de trabajo

1. Elegir idea en `ideas/ideas.md`
2. Copiar `guiones/PLANTILLA-guion.md` a `guiones/NN-titulo.md`
3. Escribir guion (~800 palabras para 6 min), con fuentes al final
4. Revisar con `produccion/checklist.md`
5. Grabar / generar voz y editar
6. Al publicar, registrar en `publicados/README.md`

## Reglas

- No reutilizar código ni guiones de `minuto-cosmico` ni `trucos-de-ia-en-1-minuto`. Este repo es independiente.
- Cada guion cita sus fuentes. Nada de afirmar sin verificar.
- Nada de consejos médicos. Solo curiosidades y divulgación.
- Hablarle al adulto, no al niño. No marcar como "hecho para niños".
